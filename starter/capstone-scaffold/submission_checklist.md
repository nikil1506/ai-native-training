# Submission checklist
- [ ] Repository builds from a clean clone (`python scripts/doctor.py`)
- [ ] `spec.md`, `plan.md`, `review-findings.md`, `decision-log.md`
- [ ] `eval/` (>= 15 cases, category on each, held-out group), threshold script, baseline + after reports with one measured improvement
- [ ] `reports/cost-report.md` (top three costs) and at least one saved trace
- [ ] `threat-model.md` with two attacks tried and fixed (with before/after evidence)
- [ ] State saved and resumable; approval step for risky actions; guarded action documented
- [ ] No secrets, no real customer data, no production credentials
- [ ] `REFLECTION.md`: what you would do differently
- [ ] 7-minute demo prepared; 30/60/90-day adoption plan drafted
