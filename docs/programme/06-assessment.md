## Assessment

Practical, not quiz-based. You are judged on what you can build, check and explain, working on your own.

A1 Day 5 · Review a flawed agent-written PR

#### 1 h

You receive a pull request written by an agent. It has several problems: a missed edge case, a made-up API call, an unsafe default, a test that checks nothing, and a change nobody asked for. You may use the review checklist and your own notes.

**Task.** Find and write down the problems, rank them, and decide merge or rework with reasons. Scored on the problems found, the reasoning and a clear decision.

A2 Day 10 · Find the cause in failing traces

#### 1 h

You receive three traces of agent runs that failed: the context grew too large, a vague tool description caused the wrong tool, and a retry loop never ended. You may use the trace-reading guide.

**Task.** Name the cause of each, suggest a fix, and say how you would test the fix with an eval. Scored on the diagnosis and the quality of the test you propose.
