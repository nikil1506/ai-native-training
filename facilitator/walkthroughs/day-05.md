# Day 5 guided walkthrough script: Agents across the SDLC, parallel work, Week-1 checkpoint

45 minutes, live-coded; **record it** so a participant who falls behind can replay it.

## L6

**Guided start (from the lab):**

The facilitator shows an example `artifacts/` folder and one written go / no-go decision.

**Live-code, in order:** the first one or two Tasks of the lab:

1. Move the item through: refine the story → short design note → task list → code and tests → independent review → PR description. Save one markdown file per stage in `artifacts/`.
2. At each gate write go or no-go and the evidence for it.
3. Run two agents on two separate tasks at the same time using worktrees (follow the cheat sheet), then merge.
4. Write the PR description so each acceptance criterion points to a test.

**Run it:** `see docs/cheatsheets/worktree.md`

**Stop when:** the first TODO is done and the participants can continue alone. Show where the hint cards are.
