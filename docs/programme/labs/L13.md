**L13** Make it recoverable, with a human decision point*[Track B · Building agentic systems]*  (Day 12 · 2 h)

**Objective.** Make your multi-agent run survive a crash, and put a person where the risk is highest.

**Starter.** Your L12 system and a small checkpoint helper.

**Guided start.** The facilitator saves state after one step, stops the process, and resumes it.

##### Tasks

1. Save the run's state after every agent step.
2. Stop the program part-way and resume it without repeating finished steps.
3. Add an approval step before publishing: continue automatically only when the reviewer is confident and no serious findings are open; otherwise wait for a person.
4. Write a decision log: who decided, what, why, when.

##### Hint cards

- Save state before moving on, not after.
- If a step sends something, record that it was sent so you do not send it twice.
- Make sure there is only one path to the publish step.

##### Deliverables

- Your orchestrator code
- A short crash-and-resume demonstration
- Decision log

##### Acceptance criteria (tick as you go; saved in this browser)

- [ ] Resuming does not repeat finished work
- [ ] The approval step blocks when findings are open
- [ ] The decision log is complete

##### Stretch

- Handle two runs at the same time.

##### Common pitfalls

- Repeating side effects on resume
- A way around the approval step
