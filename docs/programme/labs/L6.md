**L6** A backlog item to a pull request, gate by gate*[Track A · Building with agents]*  (Day 5 · 2 h)

**Objective.** Take one small change through the whole agent-assisted process, with a decision at each gate.

**Starter.** Two small backlog items in `starter/backlog/` (pick one), your L4 repository, and a short worktree cheat sheet.

**Guided start.** The facilitator shows an example `artifacts/` folder and one written go / no-go decision.

##### Tasks

1. Move the item through: refine the story → short design note → task list → code and tests → independent review → PR description. Save one markdown file per stage in `artifacts/`.
2. At each gate write go or no-go and the evidence for it.
3. Run two agents on two separate tasks at the same time using worktrees (follow the cheat sheet), then merge.
4. Write the PR description so each acceptance criterion points to a test.

##### Hint cards

- Gates are quick: one paragraph and one piece of evidence is enough.
- Give each parallel agent a different file or folder.
- If the merge conflicts, that is normal; resolve it and note it.

##### Deliverables

- `artifacts/` folder with six files
- Merged branch
- Decision log

##### Acceptance criteria (tick as you go; saved in this browser)

- [ ] Six stage files exist
- [ ] At least one gate decision is "no-go / rework", with a reason
- [ ] The two branches merged, with any conflicts noted
- [ ] The PR description links criteria to tests

##### Stretch

- Write a small script that runs the stages in order.

##### Common pitfalls

- Skipping gates when short of time
- Two agents editing the same file
