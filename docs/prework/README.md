# Pre-work (about 3 hours before Day 1)
1. **Setup clinic (1 h, live, the day before Day 1):** install Git, Python 3.11+, an editor and your coding agent, and set up access to a model (Ollama locally, or the shared gateway: `OLLAMA_HOST=http://<gateway>:8780`, `PARTICIPANT=<your name>`). A facilitator helps until it works.
2. **Diagnostic (20 min):** `diagnostic.md`: a self-rating plus three short practical questions. It tells us where to give extra help; it does not affect your result.
3. **Primer (10 pages):** `primer.md` (plain-language LLM basics), the glossary (`docs/programme/09-glossary.md`) and `acceptable-use.md` (acceptable use and data handling).
4. **Run the setup check:** `make doctor` (or `python scripts/doctor.py`). It confirms your model access works and the starter repositories are present.
5. You should be comfortable reading and writing basic code in one language. The course uses **Python**.
