**L11** Trace it, measure it, make it cheaper*[Track B · Building agentic systems]*  (Day 10 · 2 h)

**Objective.** See exactly what your agent does, then reduce its cost without making it worse.

**Starter.** Your L10 agent and eval, plus a tracing template.

**Guided start.** The facilitator adds tracing to a small agent live and reads one trace aloud.

##### Tasks

1. Add tracing using the template: one entry per model call and per tool call, with tokens and time.
2. Produce a short report: success rate, typical and slowest time, and tokens and cost per task.
3. Reduce cost: use a cheaper model for simple steps, trim the context, cap tool output length.
4. Run the L10 eval again and write a before/after comparison that includes quality.

##### Hint cards

- Find the most expensive step first and change only that.
- Always run the eval after a cost change.
- Do not put personal data into traces.

##### Deliverables

- Tracing code
- `report.md` with before and after

##### Acceptance criteria (tick as you go; saved in this browser)

- [ ] Every run produces a complete trace
- [ ] Cost per task drops by at least 20% with quality within the tolerance you were given
- [ ] The report names the top three costs

##### Stretch

- Add an alert when a single task spends more than a set amount.

##### Common pitfalls

- Cutting cost without an eval
- Logging sensitive data
