# L4: From a vague request to a working feature (Day 3, 3 h)
Run tests: `python -m unittest discover tests` (from this folder). Read `FEATURE_REQUEST.md`, fill in `spec_template.md` as `spec.md`.
Deliverables: `spec.md`, `plan.md` (<= 5 small tasks), `deviations.md`, acceptance tests, one commit per task.
Stretch: on another branch, ask the agent to "just build it" from the raw request and compare the bugs.
